This website is an initial experiment to create a website for the Cambo Monday Walking Group
Booklets:
To Create, add remove or change a "Booklet" describing one of the group's documented walks, it should be created in its entirity as a PDF file.
These files should be added to, removed from or overwritten in the folder "booklets/pdfs" in the local version of the website (windows explorer) to add, delete or change booklets.
Once the list of PDF files in "booklets/pdfs" is as required, the option "build booklets.bat" should be run in file explorer (i.e. Not in VS Code or GitHub).
This will create the booklets in the "booklets/books" folder. 
The books will now be visible in the "Booklets" option in the website, including the selection list, and be opened as "flipbooks" on the site.
Now use VS Code to update the GitHub-hosted online website.
They can also be printed from the website (but not from a phone) - Update details to follow.
